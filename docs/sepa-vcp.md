# SEPA + VCP 盘后二筛

首版从手工股票代码或候选 CSV 开始，用独立的前复权日线执行趋势模板、市场相对强度和 VCP 形态检查。每份报告记录实际参数、输入来源和逐项结果。股票入选仍依赖通过趋势与 RS 条件。

## 运行

在仓库根目录使用 Python 3.12 环境。安装 `requirements.txt` 即可运行 JSON/CSV 模式。需要 K 线 PNG 时安装 `requirements-sepa.txt`。

```bash
python3 -m pip install -r requirements-sepa.txt
python3 -m review.sepa run --date 2026-11-18 --symbols 002100 --charts \
  --output-dir work/sepa-2026-11-18
```

`--date` 是北京时间交易日，在线运行须在收盘后。交易日末价缺失时，对应股票返回数据不可用。腾讯日线覆盖沪深，北交所股票可传入已核验的同日行情文件。`--csv` 读取 UTF-8，可带 BOM；支持 `symbol` 或 `code`，附加 `name`、`source`、`signal_date`。手工候选的信号日期未知时为空。输出目录须为新目录，单个候选取数失败会记录原因，其他候选继续计算。退出码 `0` 表示至少有一只成功计算，`1` 表示命令失败，`2` 表示报告已写出但所有候选的日线均不可用。

`--price-dir` 从 `sz002100.json` 等文件读取已完成的相同行情，便于稳定重放。输入示意只展示格式，实际分析要传入完整历史。

```json
{
  "symbol": "sz002100",
  "date": "2026-11-18",
  "adjustment": "qfq",
  "volume_unit": "lots",
  "source": "tencent",
  "bars": [
    {"date": "2026-11-18", "open": 8.49, "high": 8.54, "low": 8.25, "close": 8.39, "volume": 253813}
  ]
}
```

允许输入 `shares` 或 `lots`。下游统一为股，成交量未取得时保留 `null`。CSV 正式列出证券前缀、前复权价格、趋势状态、RS、波段数、Pivot 和失效位。JSON 还包含逐项原因、波段确认时间和事件轨迹。`quotes/` 保存本次实际消费的源数据副本与 SHA-256，可以复制为 `<symbol>.json` 后重放。历史腾讯前复权行情可能接受后来的复权调整，回测应保留当时取得的价格基准或按时点重建。

## 市场 RS

```bash
python3 -m review.sepa market-returns --date 2026-11-18 --output-dir work/sepa-rs-2026-11-18
python3 -m review.sepa run --date 2026-11-18 --symbols 002100 \
  --market-returns work/sepa-rs-2026-11-18/market-returns.json --charts \
  --output-dir work/sepa-with-rs-2026-11-18
```

市场快照按官方日历定位 63、126、252 个交易日前的收盘，使用对应日期的通达信盘后包及同份 GBBQ 复权事件。默认 RS 是 63/126/252 日价格收益分别按 40%/30%/30% 加权后的同日横截面百分位，并列取平均名次。上市、退市与停牌影响可比样本，默认排名范围明确限定为沪深盘后包筛得的有成交样本。每个快照保存样本范围和覆盖，配置要求至少 1,000 个可比样本且覆盖率至少 90%。配置 `allow_market_sample_rs: false` 可关闭此样本口径。RS 缺失会保留为数据不足，另外七项仍可检查。

## 策略口径

- 默认请求 320 根交易日线，52 周窗口使用 252 根高低价，12 个月收益使用第 252 个交易间隔。MA200 要求连续 21 个日度斜率为正。前复权全历史需要足够的预热窗口。
- 波段局部极值在右侧确认窗口结束后才可用。候选整理位在确认后固定，后续日才能检测突破。日内高点穿越与收盘站上分别记录，收盘突破需通过量比门槛，量比使用突破日之前的成交量。价格、成交量与波幅单独显示。
- 默认配置见 `config/sepa.json`。A/B 类都要求通过趋势及 RS，并取得价格和量能收缩证据。A 类等待突破，B 类为确认突破或回踩。C 类为通过趋势但形态尚未达到 A/B，D 类为趋势门槛或形态失效。其他分类保留缺行情和数据不足。同类按可用市场 RS 排序，VCP 形态分单独保留。
- 如果某个交易日只提供收盘日线，盘中穿越表示这根日线的最高价曾越过 Pivot；这条信息在收盘后才可以完整重放。

月历 MCP、每日运行、大虾皮鉴权预检及选股 MCP 工具见 [SEPA 云端运行](sepa-cloud.md)。回测需要历史候选及当时可获得的复权证据，以及独立的成交、成本与退出模型。

### 突破与下一轮整理的分界

首次收盘越过已知枢轴与放量确认是不同事件。价格仍在旧枢轴上方时，新确认的低点不能替换旧形态、抬高枢轴或抹掉待确认突破。达到量能门槛后保留确认日与原首次价格突破日；后续涨幅、回踩或迟到的量能确认不让首次突破日期重新变近。确认突破后的新形态必须独立满足收缩次数，不能拼入突破前波段。过期/失效形态作为历史展示，不作为当前待突破结构。

`vcp.analysis_version=2`，`breakout_history` 为确认突破摘要，完整事件仍在私有 `events` 中。通过 `python -m review.sepa.replay --archive <已核验旧归档> --output-root <新私有归档根>` 可在不联网的情况下重新计算；旧日期的日任务会自动创建版本修订并保留旧文件。
