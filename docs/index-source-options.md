# 三类特色指数的数据来源备选

下表是接入候选，不代表已经订阅或已经验证可取得行情。当前站点不会把不同发布者的指数当成同一个序列，也不会为这些候选自动增加付费依赖。

| 指标 | 供应商及代码 | 接入条件及口径 |
| --- | --- | --- |
| 微盘股 | 米筐 `866006.RI` 价格版；`866007.RI` 全收益版 | RQData账户及对应权限；价格版与全收益版分开选择。公开规则为沪深最小市值400只等权，并有风险证券过滤。 |
| 微盘股 | 万得 `8841431.WI` | Wind账户及指数权限；名称为万得微盘股日频等权指数，不与其他调仓频率的版本混用。 |
| 微盘股 | 同花顺 `883418` | 同花顺官方快讯确认名称及代码；日线、成分与授权接口需用iFinD账户核验。 |
| 可转债等权 | 米筐 `866005.RI` | RQData权限；价格指数，不计利息；可取得历史序列及成分的数据权限需实测。 |
| 可转债等权 | 集思录转债等权 | 按集思录规则编制，上市第二交易日纳入，停牌剔除、复牌重纳，不计利息；登录、授权及稳定数据接口需另行验证。 |
| 正股等权 | 转债映射正股去重，自编 | 可以基于现有行情做样本统计；要产生连续指数，须保存历史成分、复权与调仓规则。不能称为同花顺指数。 |
| 正股等权 | 同花顺现成序列 | 可检索“含可转债” `883980`，但目前只确认名称及代码，未证明它等于参考图的“同花顺正股等权”；须在iFinD检索准确条目和编制规则。 |

不增加数据订阅时，可沿用通达信行情自编三个序列，并明确标为自编；这需要补齐历史成分、市值及一致复权行情，不能仅将每日样本均值当成已有指数。如果采用米筐，可以统一取得微盘与转债等权，正股等权仍需自编或确认同花顺序列。严格复刻参考图需确认原图发布者使用的具体版本。
