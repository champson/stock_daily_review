# 指数成交量曲线

指数价格及成交量取自同一次腾讯不复权日线历史请求，保存在相同的 `history` 日期记录中。每条为 `date`、`close`、`volume`；`volume_unit` 保存于指数行，当前腾讯指数日线使用“手”。原始成交量不转换为成交额，也不按价格推算缺失值。

单位依据为固定上游 a-stock-data 的[腾讯K线说明](https://github.com/simonlin1212/a-stock-data/blob/f21534946c42be3ad048ac938eecb1bad84cb8ab/SKILL.md)，其中明确列出指数成交量单位为手；成交量口径更正始于V3.10.1，早于本项目原有固定实现V3.10.2。这里只补存已有返回字段，不升级接口或改变行情价格。

零成交量是有效值。缺失、负数、布尔值或非有限值保存为 `null`，保留该日价格点，成交量曲线对缺口断开。旧报告只保存价格时仍能显示价格曲线，成交量保留缺失说明；不从当前行情回填历史报告。仅有北证当日快照的回退记录不生成历史成交量。

网页默认选择中证1000（`sh000852`），可切换报告中已取得的指数，并保留用户选择。价格在上、成交量在下，共用相同的最近60个日期位置；两个图分别使用价格和成交量的纵向刻度。成交量显示为手、万手或亿手；未知单位只显示原值。所选指数缺失时明确说明，不自动改用其他指数。
