# 市场统计总览

页面在综合概览及 A 股页展示“今年、本月、本周、当天、BIAS25”统计表。范围对应用户提供的参考表，排除个人实盘、持仓及账户盈亏。参考图中的数值不作为行情数据。

## 计算口径

- 年、月、周收益分别相对上一年末、上一月末、本周一之前最后一个有效交易日的收盘；日收益相对数据源提供的前收盘。期初交易日由完整的交易所日历核验，必须取得该日收盘；不能把历史中最后一条现有价格自动视为正确锚点。各周期独立计算，不以日收益填充长期列。
- 当前 A 股来自盘后包按号段筛选的有成交证券，未核对上市名册。表中称“A股有效样本数”，不能据此声称全市场总数量。每个周期只使用有合格起止数据的样本，比例分母、均值、中位数都使用该周期的有效样本。
- 六档为 `>10%`、`(5%,10%]`、`(0%,5%]`、`(-5%,0%]`、`(-10%,-5%]`、`<=-10%`，互斥且覆盖全部有效收益。平盘单独计数，也包含在 `(-5%,0%]` 档中。计算使用原始精度，显示时再取两位小数。
- A 股及转债正股的跨期收益已接入通达信官方盘后包的批量锚点价格与 GBBQ 除权事件，按报告日口径调整期初价；每次运行最多读取三个不同的历史锚点盘后包和一份完整事件包。缺少锚点、事件依据或有效调整价的证券不纳入该周期，北交所股票因事件覆盖尚未核验仍排除。具体算法及限制见[跨期数据口径](period-data.md)。
- 可转债采用收盘报价的价格收益，未另计已支付票息现金流及再投资；沪深转债为全价申报，不把原始报价称为净价。上市日期及摘牌日期决定候选范围。正股按关联证券代码去重，同一正股对应多只转债时只计一次；没有取得正股行情的样本排除，并显示覆盖数量。
- `BIAS25 = 100 × (当日收盘 / 最近25个交易日收盘均值 - 1)`，25日包括当日，并与交易日历的最近25个开市日期逐一核对；日历或任一收盘缺失、过期、重复日期或口径不一致时不计算。
- 转债等权采用集思录发布的指数点位，准确名称为“集思录转债等权”；日收益也须取得官方前交易日点位。“微盘股指数”“同花顺正股等权”尚未选定数据来源，继续保留明确缺失原因；可选来源见[特色指数来源备选](index-source-options.md)。自算平均收益不冒充现成指数。

## 数据和兼容性

原始日报仍使用 `schema_version: 1` 和原有五个模块。可选 `market_data.convertibles` 保存当日转债行情、正股映射及来源，`market_data.calendar_basis` 保存周期锚点及25日均线所需的交易日期；`market_data.period_prices` 保存各证券的精确锚点原始价、调整价及分周期覆盖数量，不伪装为连续历史；`market_data.special_indices` 保存具名发布者指数历史及来源。`GET /api/reports` 在原始 `report` 之外返回派生的 `market_matrix`，不修改 R2 中的原报告；既有历史报告也能计算其已有数据支持的指标，缺少新价格或日历依据时对应指标留空。发布程序仍逐字段核对原报告。

界面用 `—` 表示缺失，提供逐行及逐周期原因和有效样本数。`0` 与 `0.00%` 仅表示经计算得到的零。缺少期初价格、合格复权依据、历史成分或专有指数订阅的限制，不能通过补零、复制当日数值或改名其他指数掩盖。
