# 年、月、周市场统计的数据口径

市场统计按每只证券的区间涨幅重新计算上涨、下跌、零涨幅、区间分布、均值及中位数。每日涨幅不能复制到年、月、周列。每一列的分母是同时具有报告日报价、该列精确交易日锚点和合格复权依据的有效样本数；它不是历史时点全市场股票总数。

## 股票：四个报价时点与一份除权事件表

报告日及年、月、周锚点使用通达信官方盘后包的原始收盘价。锚点是官方交易日历确认的上一年末、上一月末、上一周末最后一个交易日。新股没有锚点、停牌缺少报价、证券代码变更尚未核对时，该证券不参与对应周期统计，不能用其他日期或发行价代替。

股票的跨期报价必须处理分红、送转及配股。数据路径使用通达信官方 GBBQ 股本变迁表：

- 下载地址：`https://www.tdx.com.cn/products/data/data/dbf/gbbq.zip`。
- 官方地址出处：[通达信资料库下载地址更新通知](https://www.tdx.com.cn/article/52.html)。公告年代较早，仍须通过实际 HTTP 响应、文件结构及数据内容验收当前包。
- 解码器离线运行，使用 Python 标准库；不安装通达信 TCP 客户端，不发起 TCP 行情连接。
- 解码必须通过整包记录数、精确长度、市场、代码、日期、类别及数值校验；任何记录损坏都拒绝整包，不返回部分事件表。
- ZIP 接受有界的官方多文件容器，只读取唯一根目录 `gbbq` 主文件，不落盘解压；其他资料、映射和嵌套 ZIP 不解析、不执行。压缩包及单个成员限制 16 MiB、总声明解压大小限制 32 MiB、成员数限制 64；所有成员检查名称、重复、路径、加密和类型，主文件读取校验 CRC。拒绝目录、链接及未知压缩方法。

成功解析文件只证明格式完整，不能单独证明来源真实、新鲜度或市场覆盖。采集器还须保留请求日期、来源 URL、抓取时间及文件摘要，核对实际市场覆盖。只有在该市场的完整事件源已验收后，某证券“没有事件”才可作为不变换价格的依据。北交所覆盖未验证时继续排除该部分股票，不用沪深样本冒充完整全市场。

## 报告日归一的仿射前复权

只把 `锚点日期 < 除权日 <= 报告日期` 的 category=1 事件用于计算。每条事件的分红、送转、配股数量均为每 10 股口径：

```text
m = (10 + 送转股 + 配股) / 10
c = (分红 - 配股 × 配股价) / 10
单事件调整价 = (原始价 - c) / m
```

从报告日 `A=1, B=0` 开始，按除权日从近到远回溯：`A_new=A/m`，`B_new=B-A_new*c`。锚点在报告日口径下的价格为 `A × 原始锚点收盘价 + B`；区间涨幅为 `报告日原始收盘价 / 调整后锚点价 - 1`。保留计算精度，展示时才格式化，不预先按桌面行情的分位舍入。数据口径标记应为“通达信 GBBQ 仿射前复权（报告日归一，未四舍五入）”。

例如，原始锚点价 100 元，之后先每 10 股派现 2 元、再每 10 股送 10 股，调整后锚点为 `(100 - 0.2) / 2 = 49.9` 元。若先送股再派现，则为 `100 / 2 - 0.2 = 49.8` 元，因此不能交换事件顺序，也不能只使用送股比例而忽略现金分红。停牌期间发生的事件仍按日期位置复合，不要求除权当天存在成交日线。

未来除权事件不提前生效；锚点当日除权已反映在其收盘价，不再次施加。同日重复除权事件缺少可核对的先后顺序、区间内含尚不支持的缩股、权证或不明事件（类别 11–15）、调整后锚点非正时，排除该证券并保留原因。其他股本快照不参与价格复权。此口径是调整后报价涨幅，不等同于含现金再投资的投资组合总回报。

真实文件中的市场 99 记录保留为 `tdx99`，不视为沪深京证券，也不参与股票复权。类别 15 保留但不推断字段含义。`1899-12-30` 空日期记录也保留；若属于 category=1 且四个事件字段全为零，则其变换明确为 `m=1,c=0`，可作为空操作处理；任何非零事件缺少日期都排除该证券，不能猜测发生时间。

区间端点存入独立的紧凑数据合同，保留锚点日期、原始价、调整价、方法、来源与覆盖统计；不能伪装成连续历史日线，否则均线或 BIAS 会错误消费稀疏数据。

## 可转债和正股

可转债使用相同日期的原始全价收盘报价计算区间价格涨幅，不额外计入已支付票息及再投资，不套用股票除权规则。上市或摘牌日期、转债映射和报价有效性须按报告日过滤。当前映射表不是历史时点名册，因此历史样本完整性须单独说明。

正股按合格转债映射去重，从同份 A 股复权结果取值；一只股票对应多只转债时只计算一次。每个周期仍按该周期可验证的正股样本重新计算均值和中位数。
